# kirbyuse

Composables for Kirby Panel plugins, typed by [kirby-types](https://github.com/johannschopplich/kirby-types).

## Conventions

- A wrong or missing Panel type is fixed in kirby-types, whose `/audit-panel-types` skill audits the types against the Kirby source and checks kirbyuse against them; a stopgap here carries a `// kirby-types` comment naming the gap.
- A change spanning both repos releases kirby-types first, then kirbyuse.
